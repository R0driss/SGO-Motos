# 🏍️ SGO-Motos

Sistema Web para Gestão de Oficinas Mecânicas.

O **SGO-Motos** foi desenvolvido com o objetivo de facilitar o gerenciamento de oficinas mecânicas, permitindo o cadastro de clientes, motocicletas, produtos e ordens de serviço em um ambiente simples, organizado e acessível pela web.

## Descrição

O SGO-Motos é uma aplicação web desenvolvida para auxiliar oficinas mecânicas no controle de seus serviços e clientes.

O sistema centraliza as principais informações da oficina em uma única plataforma, proporcionando maior organização, rapidez no atendimento e controle das atividades realizadas.

---

## Funcionalidades

### Autenticação
- Login de administrador
- Controle de acesso ao sistema

### Clientes
- Cadastro de clientes
- Listagem de clientes
- Atualização de informações
- Exclusão de clientes

###  Motocicletas
- Cadastro de motos
- Associação da motocicleta ao cliente
- Consulta das motos cadastradas

### Produtos
- Cadastro de produtos
- Controle de estoque
- Atualização de quantidade
- Exclusão de produtos

### Ordens de Serviço
- Cadastro de ordens de serviço
- Associação ao cliente e motocicleta
- Gerenciamento dos serviços realizados
