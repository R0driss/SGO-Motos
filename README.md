# SGO-Motos

Sistema de Gestão de Oficinas Mecânicas desenvolvido para auxiliar no gerenciamento de clientes, motos, produtos e ordens de serviço.

## Integrantes

* Ana Beatriz Leite Damascena
* Rodrigo dos Santos Albuquerque

## Descrição

O SGO-Motos é um sistema web desenvolvido com o objetivo de melhorar a organização e o gerenciamento de oficinas mecânicas, centralizando informações relacionadas aos clientes, veículos, estoque e serviços realizados.

## Funcionalidades

* Login de administrador
* Cadastro de clientes
* Cadastro de motos
* Controle de produtos e estoque
* Gerenciamento de ordens de serviço

## Tecnologias utilizadas

* Python
* Flask
* HTML
* CSS
* SQLite
